# Portfolio di Davide Di Biasio

Il mio sito personale: chi sono, competenze, progetti e contatti.

In alto c'è il cielo vero sopra Fondi visto dalle Crocette, calcolato sul momento: posizione di Sole, Luna, pianeti e stelle, fase lunare, alba e tramonto, colori del cielo in base all'ora e al meteo.

Fatto con Angular 22.

## Avvio in locale

```bash
npm install
npm start
```

Poi apri `http://localhost:4200/`.

## Build e test

```bash
npm run build   # build di produzione in dist/
npm test        # test unitari con Vitest
```
